# Muthumari Bankers

Website for Muthumari Bankers, a gold loan shop at Melathaniyam Post, Ponnamaravathi Taluk, Pudukkottai District, Tamil Nadu.

- Tamil / English language switch
- Interest calculator (2% per month, simple interest)
- Call and WhatsApp buttons
- Light and dark mode, mobile friendly

## Files
- `index.html` : the whole website (HTML, CSS and JavaScript in one file)
- `assets/` : logo (PNG and SVG)

## Edit
- Phone number: search for `PHONE` in `index.html`
- Interest rate: search for `P*2/100*m` in `index.html`

## Host free on GitHub Pages
Settings > Pages > Deploy from a branch > `main` / `(root)` > Save.
